US Household Income Data Analysis
This project involves cleaning and analyzing household income data in the United States using SQL and CSV files. The goal is to prepare the data for reporting and visualization by identifying patterns, trends, and cleaning issues.

Project Files
USHouseholdIncome.csv - Raw household income dataset.

USHouseholdIncome_Statistics.csv - Supplementary dataset with statistical summaries.

US_HOUSE_HOLD_INCOME_DATA_CLEANING.sql - SQL script for cleaning the data.

US_HOUSE_HOLD_INCOME_EXPLORATORY_DATA_ANALYSIS.sql - SQL script for exploratory data analysis (EDA).

Objectives
Clean raw data for consistency and accuracy.

Perform exploratory data analysis using SQL.

Identify trends in household income across states and cities.

Prepare data for use in BI tools or further analysis.

Tools Used
SQL (MySQL or compatible)

CSV files (opened via any spreadsheet tool or SQL import)

Optional: BI tools like Power BI or Tableau for visualization

How to Use
Import the CSV files into a SQL database.

Run US_HOUSE_HOLD_INCOME_DATA_CLEANING.sql to clean the data.

Run US_HOUSE_HOLD_INCOME_EXPLORATORY_DATA_ANALYSIS.sql to explore and analyze the data.

Example Analysis
Income distribution by state and city

Identifying cities with highest and lowest income

Detecting data outliers

Summary statistics such as average, median, and range
